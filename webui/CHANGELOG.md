# Changelog

## 0.1.0-pre1 — PRE-RELEASE

Первый публичный пре-релиз. Не является стабильным: приёмочные испытания на
реальном Keenetic/aarch64 не проводились.

Добавлено:

- изолированный экземпляр hrdns/smartdns: собственные каталоги `/opt/etc/forksmartdns`,
  `/opt/var/lib/forksmartdns`, `/opt/var/log/forksmartdns`,
  `/opt/var/run/forksmartdns`, `/opt/share/forksmartdns`, свой PID, конфиг, логи,
  бинарник и init-скрипт;
- отдельный экземпляр lighttpd (или BusyBox httpd) на порту WebUI;
- WebUI на vanilla JS без сборки и внешних CDN: обзор, Query Log, кэш, upstream
  (UDP/TCP/DoT/DoH/H3/DoQ), слушатели, группы, правила доменов, списки, клиенты,
  IPSet/NFTSet, настройки, служба, бэкапы, конфигурация, «О системе»;
- использование встроенного stats-моста hrdns для статистики, журнала и кэша;
- структурированные блоки `fsd:*` в конфиге + сырой редактор;
- статическая валидация директив и пробный запуск ядра на копии конфига;
- применение конфигурации с автоматическим backup и откатом при ошибке;
- аутентификация: сессии, CSRF, ограничение попыток входа, смена пароля;
- backup/restore tar.gz, ротация, загрузка/скачивание;
- `forksmartdnsctl` для установки/диагностики;
- `install.sh` одной командой с проверкой портов, зависимостей, целостности
  файлов по MANIFEST и rollback при неудачной валидации;
- `uninstall.sh`, не затрагивающий штатный hrdns;
- документация, unit-тесты JS и эмуляционные тесты API/HTTP/install.

Известные ограничения: см. `docs/COMPATIBILITY.md` и `docs/TEST-REPORT.md`.
