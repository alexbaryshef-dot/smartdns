# Если что-то не работает

## Панель не открывается

1. Проверьте, что служба запущена:
   ```sh
   forksmartdnsctl status
   ```
2. Проверьте порт:
   ```sh
   netstat -ltn | grep 3636
   ```
3. Посмотрите лог веб-сервера:
   ```sh
   tail -n 100 /opt/var/log/forksmartdns/web.log
   ```
4. Если `3636` занят штатным hrdns — переустановите с `--ui-port 3637`
   (порт панели хранится в `instance.env`).

## «Stats-мост недоступен», пустые статистика/журнал/кэш

- В конфиге должно быть `ui-enable yes` и `ui-listen 127.0.0.1:<порт>`.
- Порт должен совпадать с `FSD_UI_INTERNAL_PORT` в `instance.env`.
- Ядро должно быть hrdns (со встроенным stats-мостом). С generic `smartdns`
  эти страницы работать не будут — это ожидаемо и помечено в UI.
- Проверьте лог ядра:
  ```sh
  grep -i 'ui\|bridge\|listen' /opt/var/log/forksmartdns/forksmartdns.log
  ```
- Мост слушает только loopback; `nc`/`wget` должны быть доступны.

## Служба не запускается

```sh
forksmartdnsctl diagnose
tail -n 100 /opt/var/log/forksmartdns/forksmartdns.log
tail -n 100 /opt/var/log/forksmartdns/web.log
```

Частые причины:

- порт DNS занят (`53` уже слушает штатный hrdns) → используйте `5353`;
- конфиг не прошёл валидацию → `forksmartdnsctl check`;
- нет прав/каталогов → проверьте владельца `/opt/var/*/forksmartdns`;
- бинарник ядра не запускается на этой архитектуре → `"$FSD_CORE_BIN" -v`.

## «Конфигурация не прошла проверку»

Ответ API содержит `errors` и `runtime.log`. Смотрите строки с `ERROR`.
Типичные причины:

- опечатка в директиве (ядро такие игнорирует, но валидатор блокирует);
- неверный IP/CIDR/домен;
- незакрытый `group-begin`;
- отсутствующий файл списка;
- `bind` с неверным адресом/портом.

Исправьте и повторите «Проверить». Изменения не применяются, пока есть ошибки.

## 403 CSRF

- Страница устарела после смены пароля/истечения сессии — обновите и войдите.
- Запрос идёт с другого origin — панель должна открываться только с того же
  адреса (Host/Origin).
- Изменяющие действия должны быть POST; GET для них возвращает 405.

## Не пускает в панель

- 5 неудачных попыток → блокировка на 5 минут (файл в `run/login-fail.*`).
- Забыли пароль:
  ```sh
  forksmartdnsctl passwd
  ```
- Потерян setup-token до первой настройки — удалите `auth.conf` нельзя без
  пароля; проще задать пароль через CLI:
  ```sh
  forksmartdnsctl passwd
  ```
  и войти.

## DNS не резолвит

- Клиенты всё ещё используют порт `53`, а наш резолвер слушает `5353`.
  Направьте клиентов на `5353` или поставьте `--dns-port 53` (если порт свободен).
- Проверьте upstream: `forksmartdnsctl diagnose`, Query Log.
- DoH/DoT не работают: проверьте время на роутере, `ca-file`/`ca-path`, не
  истёк ли сертификат; для теста можно `-no-check-certificate` (небезопасно).

## Query Log пуст

- Проверьте `ui-enable yes` и доступность моста.
- `ui-days`/`ui-max-mb` могли ограничить хранение.
- Если ядро — generic smartdns без моста, журнал недоступен (пометка в UI).

## IPSet не заполняется

- Нужен пакет `ipset` и поддержка в ядре:
  ```sh
  opkg install ipset
  ipset list
  ```
- Проверьте `ipset-timeout` и правила `ipset`.
- NFTSet на Keenetic обычно недоступен (нет nftables) — это ожидаемо.

## Backup не создаётся

- Проверьте место: `df -h /opt`.
- Каталог `/opt/var/lib/forksmartdns/backups` должен быть доступен root.
- Ошибка восстановления: архив проверяется статически и пробным запуском; при
  ошибке текущая конфигурация откатывается.

## «Text file busy» при обновлении

Установщик копирует новый бинарник во временный файл и делает `mv`, поэтому
проблема не должна возникать. Если возникла — остановите службу
(`forksmartdnsctl stop`) и повторите `--upgrade`.

## Штатный hrdns перестал работать

Наш проект не должен его затрагивать. Проверьте:

- не совпадают ли порты (`3636`/`53`);
- не перезаписали ли вы вручную `/opt/etc/HydraRoute/dns`;
- `md5sum` файлов штатного hrdns до/после.

Если сомневаетесь — удалите наш экземпляр (`uninstall.sh`) и перезапустите
штатную службу.

## Сбор диагностики

```sh
forksmartdnsctl diagnose
forksmartdnsctl paths
forksmartdnsctl check
tail -n 200 /opt/var/log/forksmartdns/forksmartdns.log
tail -n 200 /opt/var/log/forksmartdns/web.log
```
