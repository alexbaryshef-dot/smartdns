# Совместимость и матрица возможностей

Статус: **PRE-RELEASE**. Матрица отражает реально реализованное поведение кода,
а не результаты испытаний на всех моделях Keenetic.

## Платформа

| Компонент | Поддержка | Комментарий |
|---|---|---|
| KeeneticOS + Entware | да | целевая платформа |
| aarch64 / mipsel / mips | да (код) | архитектура бинарника — та, что уже установлена |
| BusyBox ash | да | весь backend на POSIX sh |
| systemd | не используется | init-скрипт + rc.d/rc.local |
| Docker | не используется | — |
| nftables | обычно нет | NFTSet помечается как неподдерживаемый |
| ipset | при наличии пакета | иначе пометка «частично» |

## Версии ядра

| Источник | Версия | Состояние |
|---|---|---|
| готовый бинарник форка в истории репозитория | 1.0.0 | ставится установщиком; API stats-моста и опции `ui-*` совпадают с 1.2.3 |
| уже установленный hrdns | 1.2.3 / новее | используется как есть, не перезаписывается |
| исходники в репозитории | 1.2.3 / 2.0.0 | готовых бинарников нет; нужна сборка или `--core PATH` |
| Entware `smartdns` | 46.1 | fallback без stats-моста, статистика/журнал/кэш частично недоступны |

## Upstream / протоколы

| Возможность | Состояние | Причина |
|---|---|---|
| UDP (`server`) | поддерживается | — |
| TCP (`server-tcp`) | поддерживается | — |
| DoT (`server-tls`) | поддерживается | нужен CA/время |
| DoH (`server-https`) | поддерживается | нужен CA/время |
| HTTP/3 (`server-h3`) | зависит от ядра | проверка `--is-quic-supported` |
| DoQ (`server-quic`) | зависит от ядра | проверка `--is-quic-supported` |
| SOCKS5/HTTP proxy | поддерживается | `proxy-server` в сыром конфиге |
| fallback / bootstrap | поддерживается | опции ядра |
| Просмотр состояния upstream | зависит от stats-моста | иначе недоступно |

## Явные ограничения

1. Изолированный экземпляр — это **второй** DNS-сервер. Чтобы клиенты им
   пользовались, их нужно направить на его порт (`5353` по умолчанию).
2. Штатная панель hrdns и наш WebUI не могут одновременно занимать `3636`;
   используйте `--ui-port`.
3. Для статистики/журнала/кэша нужен бинарник hrdns с stats-мостом (форк 1.0.0
   подходит). С generic smartdns эти страницы помечаются как недоступные.
4. Пробный запуск ядра занимает ~3 секунды на применение конфигурации.
5. Приёмочные испытания на реальном роутере не проводились.
